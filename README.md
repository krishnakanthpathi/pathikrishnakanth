# krishnakanth

AMOLED monochrome developer portfolio for **Krishna Kanth Pathi**, configured for zero-config **Vercel** deployment.

## Stack

- React 19 + TypeScript + Vite 6
- Tailwind CSS v4 (`@tailwindcss/vite`)
- Framer Motion (`transitions.dev` motion tokens & layout pills)
- Obsidian UI 4x4 Bayer Dither Canvas

## Local Development

```bash
npm install
npm run dev
```

## Production Build & Vercel

```bash
npm run build
```

`vercel.json` configures Vite SPA routing and `dist/` output automatically.
